How to Solve Logic Grids

Every suspect, weapon, location, and time is paired uniquely in a 1-to-1 relationship. Your goal is to find all true pairs.

Basic Grid Controls:

  • Left-click / Tap: Toggle through Empty → Cross (✕) → Tick (✓).
  • Right-click: Quick-mark a cell as Cross (✕).

Deduction Rules:

  • When a Tick (✓) is placed, no other item in that row or column block can match. Place crosses in the rest of that 4x4 section!
  • Use elimination: If 3 cells in a 4x4 block row are crosses, the 4th cell must be a tick.
  • Cross-reference: If Scarlett was at 3:00 PM, and 3:00 PM was in the Library, then Scarlett was in the Library!
